# Model Artifacts

This directory stores locally generated machine learning model artifacts used by the KubeRAG MLOps Monitor.

## Cluster Health Model

The cluster health prediction model is generated by:

```bash
python app/train_model.py
```

The training script uses:

```text
data/cluster_health.csv
```

and generates:

```text
models/cluster_health_model.pkl
```

The trained model is loaded by the FastAPI application to support the `/predict-health` endpoint.

## Model Tracking

Model training metrics and artifacts are also recorded using MLflow under the experiment:

```text
kuberag-cluster-health
```

## Git Tracking

Generated `.pkl` model files are intentionally excluded from Git because they are runtime and training artifacts.

The model should be trained locally before starting the KubeRAG API.
